# Sentient Font from Fontshare

Download the Sentient font family from Fontshare:
https://www.fontshare.com/fonts/sentient

Download and place the following WOFF2 files into this directory:
- `Sentient-Regular.woff2` (Weight 400, Normal)
- `Sentient-Italic.woff2` (Weight 400, Italic)
- `Sentient-Bold.woff2` (Weight 700, Normal)
- `Sentient-BoldItalic.woff2` (Weight 700, Italic)

Until these files are placed here, the app uses `@fontsource/fraunces` as an automatic fallback.
